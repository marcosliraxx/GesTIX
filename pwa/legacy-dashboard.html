🖥️ Recursos avançados (opcional)

O monitoramento deste aparelho funciona sem instalar nada extra. O agente é opcional e habilita recursos de rede que o navegador não oferece, como ICMP real e inventário de outros aparelhos. O navegador pode exigir permissão para acessar a rede local.

  1. Para inventariar apenas o aparelho atual, não é necessário instalar o agente.
  2. O agente é executado manualmente em um computador compatível; não cria inicialização automática, não instala Python e não altera o Firewall.
  3. Se necessário, instale Python 3 a partir do site oficial e execute novamente.
  4. O agente aceita acesso somente neste computador. Abra o painel nele e use localhost:8787. Outros equipamentos continuam sendo monitorados pelos agentes instalados neles.
